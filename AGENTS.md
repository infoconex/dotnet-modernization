# AI entry point — .NET modernization

For new evaluations, start with [the authoritative evaluation process](methodology/evaluation-process.md#start-here-first-contact-protocol), then inspect the application repository and any existing evaluation. Apply [evidence standards](methodology/evidence-standards.md) and [the investigation catalog](methodology/investigation-catalog.md) as applicable.

Do **not** infer stakeholder authorization from an example or a prior application. Inspect first; interview only for material unknowns; obtain explicit consolidated scope approval before investigation issues or experiments; respect implementation, branch, merge and release boundaries. Evidence and decisions remain separate. Refer to the central methodology for the full rules—do not maintain a copy here.
