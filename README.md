# .NET Modernization

Evidence-driven research, controlled experiments, and planning for modernizing existing .NET applications without assuming that a runtime upgrade is the first step.

This repository will contain reusable evaluation methodology, cross-project technical research, project-specific assessments, verification evidence, and links to publication planning.

The documentation structure and the first RecordSift evaluation are being prepared on a review branch. Application source code and production changes remain in their own repositories.
