# Article planning and evidence mapping

This directory links engineering evidence to future articles for coding.infoconex.com. Publication-ready drafts and website layout belong in the site's own repository.

Current article evidence map: [RecordSift native-first technical discovery walkthrough](recordsift-technical-discovery-outline.md) — a companion to the concise methodology article, with concrete claims deferred until actual commands and outputs are captured.

Proposed RecordSift sequence:

1. Establish a trustworthy .NET Framework modernization baseline.
2. Understand what traditional MSBuild projects really import.
3. Centralize shared compiler properties safely.
4. Reproduce a Windows .NET Framework build in a container.
5. Build traditional .NET Framework projects without Visual Studio Build Tools.
6. Protect APIs, resources, assembly identities and package contracts ahead of SDK conversion.

An introductory article can link to these independent walkthroughs. Separate article topics only when they present a meaningful distinct concept or reproducible experiment. In particular, avoid an article for every possible MSBuild configuration file.
