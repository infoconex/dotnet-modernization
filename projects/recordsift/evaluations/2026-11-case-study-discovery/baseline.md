## 6. Quality, trust boundaries and runtime constraints

- **Import ownership:** caller owns `TextReader` / `Stream` and chooses positive per-call input budgets. Application does not persist data or invoke network services as part of the import API. [Getting started](https://github.com/infoconex/RecordSift/blob/68fdee8210f2cde71674250ce56d110b8ffeeac3/docs/usage/getting-started.md).
- **CSV security:** decoded-character limit, strict optional decoding, structural source diagnostics and fail-fast/continue-on-error validation semantics. Full input parsing is eager. [CSV source adapter](https://github.com/infoconex/RecordSift/blob/68fdee8210f2cde71674250ce56d110b8ffeeac3/src/RecordSift.Infrastructure.Csv/CsvRecordReaderAdapter.cs).
- **XLSX security:** bounded compressed bytes and rows/columns/cells; ZIP package entry/expanded byte/shared-string checks; prohibited DTD/external XML resolution in preflight; recognized external-link/VBA payload rejection. ExcelDataReader and underlying ZIP/XML allocations mean these controls do not prove absolute process-memory bounds, complete malicious-input resistance or immediate cancellation. [XLSX adapter](https://github.com/infoconex/RecordSift/blob/68fdee8210f2cde71674250ce56d110b8ffeeac3/src/RecordSift.Infrastructure.Xlsx/XlsxWorksheetReaderAdapter.cs).
- **Diagnostics and reporting:** source/row/field coordinates and standardized message codes. Avoid assuming diagnostic CSV is spreadsheet-injection safe or that arbitrary caller-controlled opaque metadata is safe for all downstream logs/renderers. [Security assessment](https://github.com/infoconex/RecordSift/blob/68fdee8210f2cde71674250ce56d110b8ffeeac3/docs/engineering/release-0.1-security-assessment.md), [JSON adapter](https://github.com/infoconex/RecordSift/blob/68fdee8210f2cde71674250ce56d110b8ffeeac3/src/RecordSift.Infrastructure.Reporting/JsonImportResultSerializerAdapter.cs).
- **No portability claim:** NFR-009 scoped to Windows/net48; retired cross-platform scenario does not create a future release gate. No modern-target build or runtime comparison was inspected. [Platform review](https://github.com/infoconex/RecordSift/blob/68fdee8210f2cde71674250ce56d110b8ffeeac3/docs/engineering/platform-dependencies-net48.md).
