## Application-specific interpretation

For this immutable `main` baseline, the local test-runner omission is historical; the approved fix is **already on RecordSift `release/0.2`** via PR #258, not on `main`. The highest-value *new* low-risk candidate is conditional shared `LangVersion=7.3`, preserving project overrides. SDK-only developer and corrected consumer paths are feasible but optional, and unchanged release scripts remain toolchain-sensitive. PackageReference conversion is technically independent of SDK conversion but requires format-aware guard/runner work, exact version preservation, and separate authorization.

For generalizable lessons, create dedicated notes under [research](../../../../research/README.md) only when they apply beyond RecordSift and can cite primary-source documentation.
