# Documentation templates

Start a new application evaluation from the [evaluation overview](evaluation-overview.md) template. For each meaningful hypothesis, use the [experiment record](experiment.md) template.

These are lightweight examples, not required empty files. Copy them into a real dated evaluation and replace placeholders with the actual repository SHA, environment inventory, commands, observed results, evidence and limitations.

The [methodology](../methodology/README.md) specifies minimum evidence standards. Keep research findings, engineering decisions and implemented changes separate, and do not turn a successful isolated experiment into an unqualified implementation claim.
